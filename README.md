## 📊 Data Analytics Projects
- **[Expploratory Data Analysis](https://github.com/richindata/Portfolio/blob/projects/EDA%20Daily%20Mission%20Capable.pdf)**: This project highlights my skill in exploratory data analysis using Python. This project utilized a semblance of real-world data of aircraft availability hours to determine and highlight trends. It aims to forecast daily capabilities for maintenance planning. - **[ARIMA Modeling](https://github.com/richindata/Portfolio/blob/projects/ARIMA%20Model.ipynb)**: This is a continuation of the exploratory data analysis project where I utilized my findings from the previous report to develop an Autoregressive Integrated Moving Average (ARIMA) model. It is a powerful statistical model used for forecasting time-series data.
- **[AutoML for Errors classification](https://github.com/richindata/Portfolio/blob/projects/AutoML%20Documentation.pdf)**: This is my Capstone for BS Business Analytics. In this project I integrated an AutoML Classifier to identify errors from work order documents. Utilizing MS Power BI, the automated data piepeline and transformation is fed thru a Power BI Dashboard that stakeholders use to identify data errors. This project saved $2M in additional software cost.
